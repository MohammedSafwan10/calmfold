# Code of Conduct

Calmfold welcomes people with different backgrounds and levels of experience.
These expectations apply to project issues, pull requests and discussions.

- Be respectful and specific. Explain disagreements about the work without
  attacking the person doing it.
- Make room for questions, constructive criticism and honest mistakes.
- Do not harass, threaten, discriminate, spam or publish someone else's private
  information. Unwanted sexual attention and impersonation are unacceptable.
- Respect a request to stop an interaction and follow moderation decisions.

The maintainer may remove harmful content, close discussions or restrict
participation. The response should reflect the severity and pattern of behavior;
ordinary technical disagreement is not misconduct.

For abusive GitHub content, use GitHub's **Report content** / **Report abuse**
controls or [private abuse-reporting form](https://support.github.com/contact/report-abuse).
Do not repeat personal information or allegations in a public issue. GitHub
handles reports submitted to its support service; this small project does not
have a separate private moderation inbox.

Security vulnerabilities have a separate [private reporting route](SECURITY.md).

This policy draws on the principles of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
while keeping the process proportionate to a small project.
