# Community themes

Copied unchanged from [longbridge/gpui-component](https://github.com/longbridge/gpui-component/tree/main/themes)
at the revision in `REVISION` (Apache License 2.0, © Longbridge). Each file is a
standard GPUI Kit theme set; Ottero loads them next to `../ottero.json`.

To update: copy the newer files over these, update `REVISION`, run
`cargo test -p ottero-ui` (every theme must parse and keep contrast), and
look at Notes, Tasks and Today in each one.
